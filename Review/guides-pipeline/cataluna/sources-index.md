# Cataluña pliegos de condiciones: index (fetched 2026-10-19)

Page markers: each text file has a form feed followed by a line `=== PAGE n / N ===` (n = PDF page). Every pliego is a standalone PDF in Spanish (no gazette wrapper), so each starts on PDF page 1. PDFs are in `/mnt/project-files/atlaslope/guides-pipeline/cataluna/sources/pdf/`; text made with `pdftotext -layout`. All 12 PDFs have a text layer. Eleven come from the INCAVI page https://incavi.gencat.cat/ca/normativa/plecs-de-condicions-de-les-do-catalanes (one sub-page per DO, direct `/content/dam/...` URLs); Cava comes from the Consejo Regulador. INCAVI keeps every version side by side, including proposals labelled "en tramitació" or "control de canvis"; the pick rule was: the newest text with a favourable national decision (BOE resolution of the INCAVI) or EU approval, checked against the eAmbrosia list (`/api/v1/geographical-indications`, publications) and BOE. The eAmbrosia attachments are only approval letters (1 to 10 pages), not pliegos, so they were not used as texts.

Notes:
- Status in force: the EU register lags the national decisions. Costers del Segre (AM05), Pla de Bages (July 2026), Penedès (mod 7), Catalunya (April 2026) and Montsant (May 2026) have a favourable INCAVI decision from July to September 2026 and are not yet EU-approved; the writer should cite them as "national decision, EU pending". Cava has both (BOE 20 Jan 2026, OJ C/2026/241).
- Not yet decided at national level (opposition stage, notices of 3 Aug 2026): Priorat (April 2026 text, labelling changes) and Tarragona (new modification, INCAVI files of Oct 2026). The index uses the last approved text. Priorat PDF of the pending April 2026 text and older versions (Tarragona AM06, Penedès AM06, Pla de Bages May 2026, Montsant AM06 Jan 2024) are kept in `pdf/` without text files.
- Empordà: weakest pick. INCAVI lists only "Plec Condicions DO Empordà 2022" (PDF made June 2024). eAmbrosia shows an EU publication C/2025/4117 (24 Jul 2025) and MAPA hosts a consolidated `emporda_2025_07_24.pdf`, which would be newer; www.mapa.gob.es refused the connection (same as in the CyL run) and EUR-Lex/data.europa.eu is blocked. Confirm whether the INCAVI file already includes that amendment before citing it as current.
- Alella and Terra Alta: no amendment after March 2020 found; Terra Alta INCAVI labels the file "en tramitació", yet eAmbrosia shows its approval (Ares(2020)2500017).
- Temporary modifications (art. 24 Reg. 2024/1143) are separate from the texts above and are not in them: Alella, Montsant, Pla de Bages, Terra Alta and others (Ares letters of 6 Feb 2026, 2024/2025 vintage rules) and the 2026 vintage reductions of minimum alcohol for Priorat and Conca de Barberà (Ares(2026)8001930 and Ares(2026)8007117, 19 Aug 2026; BOE-A-2026-17623). The writer should not state the base minimums as absolute for the 2026 vintage.
- Montsant: the repo already has `pliego-PDO-ES-A1550-montsant.txt` (the older AM05, December 2021, from MAPA). It was left untouched; the new text is `pliego-PDO-ES-A1550-montsant-incavi-current.txt` and the `montsant-pliego` entry points to it. Existing `<id>-doc` entries (EU single documents of 2014 to 2017) stay as they are.
- Cava is a multi-region DO (Catalonia, Aragón, La Rioja, Basque Country, Navarra, Valencia, Extremadura); one pliego for all. The Consejo Regulador file has no revision table; the "Última modificación" line was dropped in the 2026 copy.
- Section headings: all twelve use "1. Nombre protegido" ... "9. Comprobaciones" (Penedès "Controles", Cava "Comprobación del cumplimiento del pliego"). The shared `Tools/guides/extract.py` STOP pattern only knows "VERIFICACIÓN", so it found no stop heading and kept every page (control section included). I left the script untouched and made the `<id>.extract.txt` files with a copy of it whose STOP also accepts "COMPROBACI(ÓN|ONES)" and "CONTROLES" (and "9. - "); results: emporda p1-26/29, costers-del-segre p1-14/16, pla-de-bages p1-15/17, alella p1-19/21, conca-de-barbera p1-18/20, cava p1-24/25, penedes p1-29/32, catalunya p1-22/25, priorat p1-30/32, tarragona p1-30/32, montsant p1-18/20, terra-alta p1-14/16. Suggest changing the STOP regex in `Tools/guides/extract.py` the same way (the Andalucía run may need it too).
- START matched "1. Nombre protegido" on page 1 in every file. No gazette preambles; two files carry a short cover line on page 1 only.
- PDF files named "control de canvis" on INCAVI (Priorat 2021, Tarragona 2023, Conca AM05, Montsant, Pla de Bages, Penedès) were checked: page-1 headers show a clean "Versión ..." text; pdftotext cannot show tracked-change marks, so a few struck-through phrases could still read as current text. Not checked visually.
- Hosts: incavi.gencat.cat, gencat.cat, cava.wine, boe.es and the eAmbrosia API answered directly with `curl --cacert /root/.ccr/ca-bundle.crt` and User-Agent `atlaslope-sources/1.0`; www.mapa.gob.es refused, data.europa.eu returned a robot check.
