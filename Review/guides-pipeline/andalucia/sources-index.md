# Andalucía pliegos de condiciones: index (fetched 2026-10-19)

Page markers: each text file has a form feed followed by a line `=== PAGE n / N ===` (n = PDF page). Every pliego is a standalone Junta de Andalucía PDF (no gazette wrapper), so each starts on PDF page 1. PDFs are in `/mnt/project-files/atlaslope/guides-pipeline/andalucia/sources/pdf/` (named `<id>-<code>.pdf`); text made with `pdftotext -layout`. All have a text layer. All eight come from the Consejería de Agricultura, Pesca, Agua y Desarrollo Rural, page "Vinos con Denominación de Origen" (short link https://lajunta.es/6ahnc, full https://www.juntadeandalucia.es/organismos/agriculturapescaaguaydesarrollorural/areas/industrias-agroalimentarias/calidad/paginas/denominaciones-calidad-vinos-do.html); Lebrija is on the sister page "Vinos de Calidad con Indicación Geográfica" (.../denominaciones-calidad-vinos-indicacion.html). The BOJA orders of 20/05/2026 name that page as the home of the consolidated pliegos. Fetched with plain curl from www.juntadeandalucia.es (use the `www.` host; the bare host redirects). Extracts (`<id>.extract.txt`) made with `Tools/guides/extract.py`; the Andalusian pliegos use lettered sections (A NOMBRE ... I VERIFICACIÓN), which the script handles.

Notes
- Jerez and Manzanilla do NOT share one pliego: two separate consolidated PDFs (20 and 16 pages), same order and date; they share one Consejo Regulador.
- Málaga is the weak one: the Junta still lists the 2011 text as the pliego; I found no later consolidated version. Lebrija and Montilla-Moriles are modified-pliego files (2021, 2020) listed as current, not stamped "consolidado".
- Extract page ranges: sierras-de-malaga 1-8 of 10, manzanilla 1-8 of 16, jerez 1-12 of 20 (cut at section I VERIFICACIÓN; annexes dropped); the other five keep every page.
- Lebrija: EU code PDO-ES-A1478; the pliego title still reads "Vino de Calidad de Lebrija" (traditional term), name protected: Lebrija.
- Hosts: www.mapa.gob.es still refused (self-signed certificate in chain), not needed. The eAmbrosia API search endpoints were not needed.
- Fact-sheet citations so far point to the EU single documents (`<id>-doc:pN`), whose page numbers differ from these pliegos.
