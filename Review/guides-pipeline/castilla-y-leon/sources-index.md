## Cautions
- The EU single documents in `content/sources.json` (attachments for bierzo, leon, arlanza, valles, cigales, ribera, valtiendas, toro, tvz, sierra, pagos) are the short documents; none was used here. Every place has a full pliego from ITACyL.
- Version dates are read from each pliego's own revision table, not checked against eAmbrosia or BOCYL (time box). Several tables show 2026 dates (Arribes rev 4, Bierzo rev 3, Sierra de Salamanca rev 2, TVZ rev 1, Dehesa Peñalba rev 2, Abadía Retuerta rev 2, Arlanza rev 3). The pliego states national "normal" amendments are in force the day after the BOCYL publication of the ITACyL resolution, but the EU-side date can come later; some tables carry a second, later date (e.g. Sierra 29/9/2026, TVZ 23/09/2026). Check which date the guides should cite.
- Arlanza: ITACyL lists three versions (rev 3.1 "consolidado en vigor", rev 3.4 proposed with changes and consolidated). The index uses 3.1; the rev 3.4 consolidated text is also supplied. Which is in force is ambiguous (table row 3 shows 21/05/2026 and 3/06/2026).
- Repo copies: Rueda matches ITACyL rev 4 exactly. Arribes in the repo is OLD (stops at rev 3). Cebreros in the repo has the same revision table but a different text: ITACyL's newer file adds the "VINO DE PARCELA" label mention, drops a "12% vol. tintas" line and fixes a typo. Use the files here, not the repo ones.
- Tierra del Vino de Zamora: first amendment (rev 1) is very recent (decision 18/06/2026, EU date 23/09/2026 in the table, PDF made 23 Sep 2026); confirm the in-force date before citing.
- Dehesa Peñalba: the pliego mentions both PDO-ES-02592 (the number in sources.json, used on the cover) and PDO-ES-05292 (twice, in the revision table; looks like a typo).
- Sierra de Salamanca: the revision table prints the code as "A031" in places; the cover says PDO-ES-A0631.
- Toro: 25 PDF pages, pages numbered "de 20" on the cover; the extra pages are annexes after the pliego.
- Hosts: www.mapa.gob.es refused (TLS: self-signed certificate in chain, even with the proxy CA bundle); I did not try other options. ec.europa.eu and webgate eambrosia attachments answered but were not needed. itacyl.es worked directly with `curl --cacert /root/.ccr/ca-bundle.crt`.
- No scans: every PDF has a text layer. Header lines such as "Página 1 de N" in the text are the pliego's own numbering, not the PDF page.
