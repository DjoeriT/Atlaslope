# Release 50: what to test (Canarias guides)

Eleven new written guides for the Canary Islands, a Canarias tile on the Guides page, and the guide count goes up by 11.

1. Open the Guides page. A new Canarias tile with a satellite view of the islands sits with the other regions. Tap it: the region page lists its places.
2. Open Lanzarote, Gran Canaria, La Palma, El Hierro and La Gomera. Each has "Why X tastes the way it does" with its parts, a short summary and sources.
3. Open the five Tenerife places: Tacoronte-Acentejo, Valle de Güímar, Valle de la Orotava, Ycoden-Daute-Isora and Abona. Same shape.
4. Open Islas Canarias (the all-islands DO, outside Study). It now has a written Terroir section; it still shows no photos, charts or Test me.
5. Tap a "Fly to" in any of them. The map flies to the spot.
6. Check the guide count went up by 11 (73 if only Canarias is new since release 47; more if Mediterranean shipped first).
