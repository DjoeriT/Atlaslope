# Release 47: what to test (Ebro guides)

Eleven new written guides for the Ebro valley, an Ebro tile on the Guides page, and the guide count is now 62.

1. Open the Guides page. A new Ebro tile with a photo sits with the other regions. Tap it: the region page lists its places.
2. Open Navarra, Somontano, Campo de Borja, Cariñena, Calatayud, Ayles and Urbezo. Each has "Why X tastes the way it does" with four parts, a short summary and sources.
3. Open Otazu, Prado de Irache, Arinzano and Bolandín (Navarra Vinos de Pago). Same shape, shorter; they rest on the EU single document only.
4. Tap a "Fly to" in any of them. The map flies to the spot.
5. Check the guide count reads 62.
