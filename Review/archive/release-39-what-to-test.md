# Release 39: what to test

## General (every release)
Open https://atlaslope.com/ in Chrome or Safari on a Mac or iPad. Reload once with a hard refresh if a page looks stale. Anything odd: a screenshot plus the page address and what you expected is enough.

## This release
1. **Eight new guides.** Open each Andalucía place: Jerez, Manzanilla, Montilla-Moriles, Málaga, Sierras de Málaga, Condado de Huelva, Granada and Lebrija. Each page tells "Why it tastes the way it does" in four beats: the place, the weather, the ground and what the rules make.
2. **Every wine type is named.** The rules beat now names every wine type the rules protect, for example Jerez's Pale Dry, Pale Cream, Medium and Dulce, and Manzanilla Fina and Pasada. It says plainly which generosos are fortified.
3. **Flights.** Beats fly to named places, for example Doñana, the Sierra de Gibalbín (Lebrija), the Serranía de Ronda and the Axarquía (Málaga), and Sierra Nevada (Granada). Each flight lands close on the place.
4. **Read the label.** Only the label words the rules define and that the famous styles don't already cover. Granada keeps «Naturalmente Dulce».
5. **Corrected facts.** The eight Andalucía fact sheets were re-checked against the current official specifications (grapes, wine types, climate, styles). Granada's sparkling is white or rosé only.
