# Release 7, card 1: the quiz engine

    Goal:        A learner's memory of every place, and the next round of questions, follow the engine rules exactly, from a tested pure-TypeScript engine that any screen (Study, Review, Today, Progress) can call.
    Task:        Write src/quiz/ (plain TypeScript, no React, no map, no storage, no Date.now inside: the caller passes `now`): types for the answer log; replay of the log into per-place memories (`where`, `what`) with box, due date and shade; place shade; the Study plan (due, intake of five a day with focus then course order, zones after the parent); a round builder for Study and for a Review set (up to 20, due first, intro before a new place's first question, a miss re-asked once at the end, Keep going); question type by memory; the slip.
    Role/model:  BuilderBot (Opus): the quiz engine is named as complex work in the brief.
    Budget:      250k; stop and report at ~70% or after two failed tries
    Branch:      agent/builder/r7-engine (worktree)
    Context:     Review/release-7-digest.md ("Engine rules"; read the whole digest, it is one page); src/tree/types.ts and src/tree/tree.ts (Tree API: places, getPlace, children, regionsOf, placesInRegion); data/places.json fields quiz, region, parent, courseOrder, northSouth (read the first 120 lines only)
    May edit:    src/quiz/ (new: e.g. types.ts, memory.ts, plan.ts, round.ts, index.ts), tests/unit/quiz-*.test.ts, tests/fixtures/quiz-*.json
    Must not:    change data/, src/tree/, other src/ folders, other tests; add React, map or localStorage code to src/quiz/; add dependencies
    Tests:       unit tests with a fixed `now` and a small fixture tree (built from loadTree on a fixture, or the real places.json): box moves (right when due up one, right before due no change, miss down one and due now, max 5, min 1); shades (new, learning, known after two rights, solid after three rights on three days a day apart, a miss drops back); place shade is the lower memory; question type (where new: what-is-this, where learning: find-it, what only after where known: fact); intake five a day in course order, focus first, a sixth only through "Learn 5 more", none counted twice on the same day; zones not in intake until the parent is known, then in; vc never in Study intake but asked in a Review set that holds them; round of 20 with due first by most overdue, intro before a new place's first question, a miss re-asked once at the end, Keep going returns the next 20 and then nothing left; slip turns the last miss into a right for the schedule and the log keeps both; replaying the same log twice gives the same state; npm test green
    Done when:   index.ts exports the engine API (types plus functions such as replay(log, now), placeShade(...), studyRound(tree, log, now, opts), reviewRound(tree, set, log, now, opts), questionType(...), withSlip(log)) with a short doc comment each; every digest engine rule tagged [O] has a test; rules tagged [A] are each one constant or one function so they can change in one place
    Report:      300 words in the final message; [V]/[R]/[A]; list any rule you had to interpret
    Stop and ask if: two digest rules contradict each other, the data lacks a field the rules need, an existing test fails
