# Release 7, card 2: progress store and question making

    Goal:        A learner's progress survives reloads, can be saved to a file and loaded back (with an undo), and every question the engine asks comes with four fair choices and one fact to reveal.
    Task:        (1) src/quiz/store.ts: one versioned record { version, log, focus, savedAt } in localStorage under one interface (load, save, exportFile, importFile, restoreBackup), a migrate() step, an in-memory fallback when storage is blocked (with a flag the screen reads). Loading a file keeps the previous record as a backup that restoreBackup() brings back. (2) src/quiz/questions.ts: build a question for an engine RoundItem: what-is-this (the place plus three others from the askable pool, neighbours in the same study region first), find-it (the target only), fact (one of main grape, famous style, level, climate as the Köppen class with the largest share; four choices whose wrong ones are true of other places and not of this one); revealFact(place) gives the one fact shown after every answer (main grape, "local (usual)"). Choices are shuffled by a seeded random passed in, so tests are fixed.
