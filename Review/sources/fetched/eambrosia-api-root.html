Welcome to eAmbrosia API

In order to get the data through the Web Service, please use this URL:

https://webgate.ec.europa.eu/eambrosia-api/api/v1/geographical-indications

Accepted date parameters - format: yyyy-MM-dd'T'HH:mm:ss.SSS'Z'

  • modifiedOnFrom - lower bound (optional)
  • modifiedOnTo - upper bound (optional)

Example:

https://webgate.ec.europa.eu/eambrosia-api/api/v1/geographical-indications? modifiedOnFrom=2020-01-01T00:00:00.000Z& modifiedOnTo=2022-03-30T23:59:59.000Z

In order to get the information for one specific GI, please use this URL:

https://webgate.ec.europa.eu/eambrosia-api/api/v1/geographical-indications/{giIdentifier}

Example:

https://webgate.ec.europa.eu/eambrosia-api/api/v1/geographical-indications/EUGI00000001005

In order to download an attachment, please use this URL:

https://webgate.ec.europa.eu/eambrosia-api/api/v1/attachments/{attachmentId}

Example:

https://webgate.ec.europa.eu/eambrosia-api/api/v1/attachments/10717
Version: 2.5.3 2026-05-22T12:51:01.273Z
